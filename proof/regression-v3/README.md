## Keyboard objectives reviewed

The archived DEV runs retain the original v2 objectives. The Caltech Kane replay was inconclusive. An isolated local keyboard replay opened the same article through the focusable headline after 13 Tabs.

Vanderbilt’s patched Kane replay passed the original Tab-specific route with 21 trusted Tab presses and a recorded landing on the target. The original unpatched tablist already worked through Arrow Right after entering the group. The scripted repair therefore does not count as a functional keyboard fix.

## Recorded reflow checks

The IANA, NGINX, YAML, MathWorld and TOML local replays found the exact registered text and passed the normal-width check. Their passages overflowed at 320px. IANA's registered selector matched multiple cells, and the quote identified the intended cell. Getty's sealed Kane replay measured the unrepaired text fully inside the 320px viewport, so it counts as having no barrier in this rerun.

The MathWorld replay's raw Kane failure and automatic browser verdict disagree. The sealed pack records a scroll-into-view action. In the controlled Playwright reproduction, vertical scrolling left the text clipped to the right of the viewport. Scroll-into-view moved a nested container by exactly 100px and reproduced the Kane run's text bounds, while the window's horizontal offset remained zero. The vertical-only objective therefore still fails. This case shows a gap in automatic verification. Before held-out registration, reflow candidates are screened for nested horizontal scrollers that can shift the passage.

Curb Cut settings

Instant fix

Off by default. When enabled, press Alt+Shift+F or choose “Try experimental instant fix” in the popup. Curb Cut checks the page and looks for repair candidates before capturing a JPEG of the visible tab.

TypeSafe receives the screenshot, page origin and path, title, viewport size and zoom, and details about the focused element, nearby controls and up to 16 repair candidates. Those details include accessible names or visible text, element types, positions and candidate repairs.

Use this on public HTTPS pages. Curb Cut skips sensitive URLs, sign-in and payment forms, and visible text fields containing values. A proposed fix applies temporarily in the current tab. Press Escape or choose Undo to remove it.

After applying a fix, Curb Cut sends the rule, its task description, the model and confidence to the local verification queue. If the server is unavailable, the extension saves that entry locally and retries. The screenshot stays out of the queue.

Live names

With Reading view closed on a public HTTPS page, TypeSafe receives crops of unnamed links and buttons, nearby text and clues about their purpose. It may also receive a visible text sample to identify the language. Open Reading view again to see the temporary, unverified names. Turn this off or pause the page to remove them.

Keyboard help

TypeSafe receives recent navigation keys, timing and anonymous focus signals. Typed text, page text, URLs and screenshots stay out of this check. Curb Cut asks before applying a fix.

Proof recordings

Kane-verified fixes in the popup link to before and after recordings. Leave this blank to use the GitHub archive, or set a base URL for hosted evidence files.

TypeSafe connection

Bundled repairs work with no key. TypeSafe features stay off until you turn them on. With a personal key, the extension sends requests directly to TypeSafe. With an empty key, those opt-in features use the local Curb Cut server at 127.0.0.1:4317.

Match mouse

Focus a menu trigger and press Alt+Shift+M. Curb Cut attaches Chrome’s debugger to move the pointer and test keyboard input in this tab. Chrome shows a debugging bar. Escape stops the test or undoes the repair.

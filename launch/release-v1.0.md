# Curb Cut v1.0

Draft release notes. Publication is on hold. Build the extension-only attachment with `node scripts/build-extension-zip.mjs`.

Curb Cut v1.0 bundles 105 active repairs for public websites. 61 have Kane replay evidence and 44 have local contrast or language proof. The extension popup and CLI export a Markdown repair report for the site owner.

## Try it

1. Download and extract the extension zip. In Chrome, open `chrome://extensions`, enable Developer mode, choose **Load unpacked**, and select the extracted `extension` folder.
2. Open https://www.mass.edu/.
3. Press Tab until **About** is focused. Open the submenu and follow **The DHE**.

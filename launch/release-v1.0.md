# Curb Cut v1.0

Draft release notes. Build the extension-only zip with `npm run package`.

Curb Cut ships 105 repairs for public websites. 61 have Kane verification and 44 have local proof, comprising 41 contrast repairs and three development-page language repairs. The popup exports a Markdown report for the site owner.

| Study | Result |
| --- | --- |
| Held-out v6 | 76/118 local repairs across 400 scouted sites, 7/15 sampled naming tasks Kane-verified |
| Held-out v5 | 99/142 local repairs across 2,050 scouted sites, including 51/89 multi-step journeys, 11/20 random sample Kane-verified |
| Installed extension | 43/43 in the original audit, 11/11 new v5 releases and 51/51 new v6 releases |

Language repaired 0/20 held-out tasks. The optional TypeSafe Jev hotkey is off by default and repaired 3/142 held-out barriers, all hover menus.

## Try it

1. Download and unzip the [extension package](../site/assets/curbcut-extension.zip).
2. Open `chrome://extensions`, enable Developer mode, choose **Load unpacked**, and select the extracted folder.
3. Open [mass.edu](https://www.mass.edu/). Tab to **About**, open the submenu, and follow **The DHE**. Use the popup to compare the result with the fix off and on.

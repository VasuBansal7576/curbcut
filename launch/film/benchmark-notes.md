# Curb Cut motion direction

1. **Give the opening action a payoff.** Keiki sketches several ways to open its story with a single phone interaction. Open on a physical Tab key, cut to the closed Mass.edu menu, then bring the same key and the same crop back when the menu opens. [Keiki](https://aceoframes.com/case-studies/keiki)
2. **Build the transitions from the product mark.** Paper makes each action something a sheet can do. Use a single cobalt curb edge with a lime inset that drops, becomes a ramp and finally resolves to the Curb Cut mark. The bevel and shadow give the ramp depth against the cobalt field. [Paper](https://aceoframes.com/case-studies/paper)
3. **Give the number the frame.** Granola changes the scale and position of its type to suit each line. Give 95.9% the width of the picture and a single short qualifier. Give 105 its own composition beside the actual extension. [Granola](https://aceoframes.com/case-studies/granola)
4. **Crop around the action.** Jinko uses a wing to point to a fare and leaves the sky free for text. Give browser details the same treatment. Place a large verb beside the framed evidence, keep the target sharp, and use lime for the repaired state and coral for the failure. [Jinko](https://aceoframes.com/case-studies/gojinko)
5. **Let an action make the cut.** Keiki settles the interface before the eye has to read. Land a key click, mechanical strike or short air movement on each visual change, then hold the result. Carry a single line through the closing mark as Granola does with its final pen stroke. [Keiki](https://aceoframes.com/case-studies/keiki) · [Granola](https://aceoframes.com/case-studies/granola)

## Comparison after the first edit

At storyboard size the first version’s pointer and naming beats were nearly identical text cards. Ref-6 holds one large, recognizable piece of interface. I gave those beats different silhouettes, a physical cursor and a blank name tag. Ref-8 uses one oversized percentage and ample space around it. I enlarged 95.9% and put its qualifier beneath a single rule. The title collided with the raised curb, so I moved the object below the name. The original contrast crop exposed an unrelated shipping price. The revised crop isolates the measured Details link. The site-owner shot now shows the complete source-change sentence.

## Comparison after the cobalt render

The first cobalt edit held the percentage and its denominator together for nearly six seconds. Following Granola’s shifts in type hierarchy, the number now lands alone and the denominator enters on “top.” The teaser now cuts from the closed menu to the installed extension changing state and returns to the same menu. In the Kane replay, the title names the exact task, “Open About.” The closing card pairs the ramp mark with a spoken Chrome invitation and the release repository address.

## Product close-ups

On the one-frame-per-second review the first cobalt edit made the viewer divide attention between large headlines and small interface details. The revised frames devote 63–66% of the screen to the browser. Four real Reading view rows establish which names change. The Kane replay pairs the archive with a magnified About control from the same public menu. Its destination label changes on the recorded navigation frame.
